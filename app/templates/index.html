GET CONNECTED

Your graph. Your evidence.

Run this app locally with FalkorDB Cloud. No Docker installation required.

1. Create a Gemini API key

Open Google AI Studio ↗, sign in, and create an API key. Put it in GEMINI_API_KEY in the project's .env file.

2. Create a FalkorDB Cloud instance

Open FalkorDB Cloud ↗. Create an instance, then copy its connection details into the local file. Use the assigned port and username. Set TLS to match your instance.

GEMINI_API_KEY=your_key
GEMINI_MODEL=gemini-3.5-flash-lite
FALKORDB_HOST=your_database_hostname
FALKORDB_PORT=your_assigned_port
FALKORDB_USERNAME=your_username
FALKORDB_PASSWORD=your_password
FALKORDB_SSL=false
FALKORDB_GRAPH=promisegraph_demo

Use FALKORDB_SSL=true if your connection URL starts with rediss:// or falkors://; otherwise match the setting shown by your provider. Keep credentials in the local file. The interface never displays them. Settings reload on each request; save and click Check connections.
